Soundstage

Auto rewrites the script unless the writer already did, makes every missing voice and (in Advanced) every missing sound, then speaks.

Examples 

          
        

        
Start each line with a speaker's name, such as Mia:.
          Add [cues] for delivery. Or paste any text and let the writer script it.

      

      

        

          

            
Rewrite with the writer

            
Turns any text into a Drama 3 script: names the speakers, adds cues and, in Advanced, stages sounds and music. It fills the cast for you.
